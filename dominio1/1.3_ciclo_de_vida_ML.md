## 🧩 Tarefa 1.3 — Descrever o ciclo de vida do desenvolvimento de ML

<p align="justify">A ideia central desta tarefa é entender <strong>como um modelo de ML sai dos dados e chega à produção</strong>, como pode ser obtido, como é disponibilizado aos usuários, como é operado continuamente e como medimos se ele realmente funciona.</p>

<pre>
DADOS
  ↓
EXPLORAÇÃO / EDA
  ↓
PRÉ-PROCESSAMENTO
  ↓
ENGENHARIA DE ATRIBUTOS
  ↓
TREINAMENTO
  ↓
AJUSTE DE HIPERPARÂMETROS
  ↓
AVALIAÇÃO
  ↓
IMPLANTAÇÃO / DEPLOYMENT
  ↓
MONITORAMENTO
  ↓
RETREINAMENTO
  ↺
</pre>

> 🔥 DECORA: ML não termina quando o modelo é treinado. Em produção, ele precisa ser implantado, monitorado e, quando necessário, retreinado.

---

<h3><strong style='color: skyblue'>1️⃣ Componentes de um pipeline de IA/ML</strong></h3>

### 📥 1. Coleta de dados

<p align="justify">Obtenção dos dados que serão usados para desenvolver e avaliar o modelo.</p>

Exemplos:

- dados de clientes;
- transações;
- imagens;
- textos;
- sensores;
- históricos de vendas.

> **DECORA:** sem dados adequados, não existe modelo confiável.

---

### 🔎 2. Análise exploratória de dados — EDA

<p align="justify">Exploração dos dados para entender sua estrutura, qualidade, distribuição e possíveis problemas.</p>

Pode envolver:

- identificar valores ausentes;
- detectar outliers;
- observar distribuições;
- identificar correlações;
- verificar desequilíbrio entre classes;
- entender características dos dados.

> **PEGADINHA:** EDA não é treinamento do modelo. É entender os dados <strong>antes</strong> de treinar.

---

### 🧹 3. Pré-processamento

<p align="justify">Preparação dos dados para que possam ser utilizados adequadamente pelo algoritmo.</p>

Exemplos:

- tratar valores ausentes;
- remover ou tratar dados inválidos;
- normalizar valores;
- codificar categorias;
- limpar textos;
- transformar formatos.

> **DECORA:** pré-processamento = <strong>preparar os dados</strong>.

---
